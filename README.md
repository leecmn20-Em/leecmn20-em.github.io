# CMN.LOG

A responsive personal developer blog homepage built for GitHub Pages.

## Preview locally

Open `index.html` in a browser, or run a small static server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Customize

- Update the name, biography, and links in `index.html`.
- Replace the sample posts with your own writing.
- Change the color tokens at the top of `style.css`.

GitHub Pages serves this site directly from the `main` branch.
