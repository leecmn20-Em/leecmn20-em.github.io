## 설치 방법

- theSensor APK 설치 파일을 다운로드받아 실행합니다.
- 현재 해당 앱은 공식 서명을 받지 않았으므로, 보안 정책을 해제하고 설치해야 합니다.
  - **설치 후에 반드시 보안 기능을 재활성화하는 것을 잊지 마세요!**

## 기능

- theSensors에서 제공하는 기능은 크게 가시적인 센서 UI와 녹화 기능으로 나눌 수 있습니다.
- 각각의 센서 UI에서는 해당 센서의 실시간 값과 신호 특성에 대해 읽어볼 수 있습니다.
- 녹화 UI에서는 선택한 센서들의 값을 일정 시간 동안 기록하여 .csv 파일로 저장할 수 있습니다.
